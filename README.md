# KEC Navigator — Type C

한국전기설비규정(KEC) 조회 도구의 디자인 시안 중 하나. **"규정 라이브러리 + 몰입형 문서 리더"** 콘셉트로,
Type A/B와 달리 첫 화면에 AI 질문 입력창을 두지 않고, AI 채팅과 원문을 상시 좌우로 노출하지도 않는다.

## 핵심 구조

- **라이브러리(홈)**: 검색 · 버전 선택 · 다크 모드만 있는 간결한 헤더 + 8개 대분류 카탈로그 카드 + 최근 본 조항 /
  자주 찾는 조항(예시) / 추천 탐색 경로 섹션.
- **몰입형 문서 리더**: 좌측 목차, 중앙 원문, 우측 북마크·메모·관련 조항의 3열 레이아웃. AI는 상시 노출되지 않고
  ① 본문 텍스트 선택 시 뜨는 컨텍스트 메뉴, ② 우측 하단 "AI 도우미" 버튼으로 여는 하단 슬라이드업 패널을 통해서만
  필요할 때 열린다.
- **검색**: 헤더 검색창 또는 ⌘/Ctrl+K로 여는 오버레이. 조항 번호·제목·미리보기·소속 대분류를 보여주고 선택 시
  해당 조항의 리더 화면으로 이동한다.

## 데이터 정직성

- 실제 목차 데이터가 연결된 것은 "공통사항" 하위 8개 조항뿐이며, 나머지 대분류는 "표지만 연결됨"으로 명시한다.
- 개별 조항 원문 본문은 존재하지 않으므로 항상 "원문 미연결" 상태를 정직하게 표시하고, 표지 이미지를 조항 본문처럼
  보여주지 않는다.
- 북마크·메모는 실제로 동작하지만 브라우저 세션에만 저장되며, "자주 찾는 조항"은 실사용 통계가 아닌 큐레이션 예시임을
  화면에 명시한다.
- AI 응답은 실제로 연결되어 있지 않으며, 모든 응답은 디자인 시안임을 알리는 고정 문구로 대체된다.

## 개발

```bash
pnpm install
pnpm dev      # http://localhost:5173 (또는 PORT 환경변수)
pnpm build
```

GitHub Pages 배포는 `main` 브랜치 push 시 `.github/workflows/deploy-pages.yml`을 통해 자동으로 이루어진다.
